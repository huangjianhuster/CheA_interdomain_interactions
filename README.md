# CheA_interdomain_interactions
Data involved in the HyRes simulation study of domain interactions of the CheA kinase

## AlphaFold predictive modes for the CheA kinase dimer
dir: `cheA_models`
This dir contains the five AlphaFold2 predictive models among which the model-4 ranked the highest in prediction accuracy scores.

## trans-productive P1-P4 interaction mode
dir: `productive_modes`

Representative snapshots for the two identified trans-productive mode:
- `mode1.pdb`: the major binding mode
- `mode2.pdb`: the minor binding mode

## P1 dimerization modes
dir: `P1_dimer`

Represebtative snapshots of P1 dimerization from the P1 dimer HyRes simulation.
- `major.pdb`: the major binding mode
- 'minor.pdb': the minor binding mode
